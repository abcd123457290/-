# 穹 - 战斗像素动画

全部正式帧均为 64x64 RGBA PNG，透明背景。

## 动画

- `crouch_unarmed`：空手单膝蹲，前脚踩地、前膝抬起，后腿折回并让后膝落地。
- `crouch_bat`：持棒单膝蹲，腿部结构同空手版本；左右方向球棒朝前。
- `walk`：空手行走，四方向，每方向 4 帧。
- `walk_bat`：持棒行走，四方向，每方向 4 帧；左右方向为单手握住握柄、棒身朝行走方向近水平伸出。
- `bat_swing`：持棒横挥，四方向，每方向 5 帧。
- `bat_throw`：投掷球棒，四方向，每方向 5 帧；第 2 帧释放。
- `punch`：空手挥拳，四方向，每方向 5 帧。
- `bat_spin`：独立球棒旋转，一圈 8 帧，中心点固定为 (32, 32)。
- `unarmed`：空手待机，方向顺序为下、左、右、上。

每种攻击均包含基础人物图集、纯特效图集和人物加特效合成图集。游戏中需要动态改变特效颜色或透明度时，使用 `vfx` 图集单独渲染；直接播放时使用 `with_vfx` 图集。

帧率、命中帧和图集布局见 `combat_sprites.json`。
