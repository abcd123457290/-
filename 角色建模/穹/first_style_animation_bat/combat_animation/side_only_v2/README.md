# Side-only v2 animation assets

This pack is generated by `tools/build_side_only_assets.py` from three
preserved green-screen masters. Transparency is created first with
`remove_chroma_key.py --auto-key border --soft-matte --despill`.

- Every runtime frame is 64x64 RGBA with pivot `(32, 60)`.
- Direction order is only `left`, `right`; facing uses horizontal memory.
- Right is the authored direction. Left is an exact mirror about x=32.
- All 18 player frames share source scale `0.130405405`.
- All 8 monster frames share source scale `0.110919540`.
- No C++ file is read or modified by this builder.

Runtime animations:

- `player_idle`: 4 frames/direction, 5 fps, pivot `(32, 60)`, sheet `角色建模/穹/first_style_animation_bat/combat_animation/side_only_v2/spritesheets/qiong_idle_side_4frames.png`.
- `player_walk`: 4 frames/direction, 12 fps, pivot `(32, 60)`, sheet `角色建模/穹/first_style_animation_bat/combat_animation/side_only_v2/spritesheets/qiong_walk_side_4frames.png`.
- `player_attack`: 10 frames/direction, 25 fps, pivot `(32, 60)`, sheet `角色建模/穹/first_style_animation_bat/combat_animation/side_only_v2/spritesheets/qiong_attack_side_10frames.png`.
- `monster_attack`: 8 frames/direction, 20 fps, pivot `(32, 60)`, sheet `角色建模/怪物/selected_monster_knight/side_only_v2/spritesheets/monster_attack_side_8frames.png`.

See `manifest.json` for explicit frame paths and `qa_report.json` for
dimension, alpha-edge, mirror, body-axis and foot-baseline checks.
