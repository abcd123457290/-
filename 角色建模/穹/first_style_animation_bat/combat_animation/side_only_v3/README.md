# Side-only v3 high-detail runtime assets

Generated by `tools/build_side_only_v3_assets.py`. No C++ file is read or
modified by the builder.

Rebuild from the preserved project-local masters with
`python -B tools/build_side_only_v3_assets.py`. The builder uses Pillow,
NumPy, SciPy and the installed imagegen chroma-key helper.
Runtime PNG/GIF/JSON files are written to same-directory temporary siblings
and atomically replaced; generated directories are never cleared up front.

- Runtime character frames: 96×96 RGBA, pivot `(48, 90)`.
- Directions: `left`, `right`; right is authored, left mirrors about x=48.
- Standing visual body height: 56px.
- Idle source scale: `0.189011885` (4 frames, 5 fps).
- Corrected walk source scale: `0.196925217` (8 frames, 12 fps).
- Attack source scale: `0.219794466` (10 authored frames; runtime C++ retimes to 0.32s with contact at 0.13s).
- Death source scale: `0.175500000` (8 authored frames, non-looping).
- Finisher icon: `icons/qiong_finisher_icon_64.png`, with a true 32×32 preview.

The lower walk row in the original idle/walk master is intentionally excluded:
its bat dragged along the ground. `qiong_walk_8frames_chroma.png` replaces it
with an eight-frame cycle whose two visible hands grip the bat in front of the
chest/waist. The bat points diagonally forward-right, never crosses behind the
shoulder or body, and stays above ground.
