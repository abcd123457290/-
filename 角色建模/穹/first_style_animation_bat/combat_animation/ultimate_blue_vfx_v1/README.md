# Ultimate Blue VFX v1

Generated by `tools/build_super_bat_assets.py` with Pillow and nearest-neighbor
sampling.  The `actor_frames` directory is a byte-for-byte copy of the existing
64x64 Qiong identity frames.  Runtime VFX are separate layers so the AI guide
character never replaces the established player model.

- `actor_frames`: 64x64 identity layers, pivot `(32, 60)`.
- `vfx/basic_swing`: 192x192, original arc scaled exactly 1.5x and recolored blue.
- `vfx/activation`: 192x192 procedural pulsing bat energy, four directions.
- `vfx/ultimate_combo`: 512x512, four-direction forward 132-degree attacks.
- `composite/ultimate_combo`: the same VFX over the matching byte-exact 64x64
  basic actor frame, centered at top-left `(224, 224)` on every 512x512 cell.
- `vfx/endpoint_explosion`: 512x512 directionless terminal AOE.
- `projectile`: 64x64 eight-frame blue spinning super-bat.
- `style_guides/frames`: cleaned/cropped guide panels only; they are not identity layers.

The five combo peak radii are 144, 160, 176, 196 and 216 pixels.  Their pivot is
always `(256, 256)`, and pixels behind the player are rejected by QA.  The old
`ultimate_combo_radial_draft_*` files remain style drafts and are excluded from
`sprites.json` and all final sheets.
